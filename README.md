# Battlesky

A Unity multiplayer game project built with [Mirror](https://mirror-networking.com/) networking.

## About

Battlesky is a Unity game featuring:
- Multiplayer networking via Mirror
- Custom 3D models, skybox, and shaders
- Scene-based gameplay

## Getting Started

1. Install [Unity](https://unity.com/) (version from `ProjectSettings/ProjectVersion.txt`).
2. Clone this repository:
   ```
   git clone https://github.com/DeveloperAJ2799/battlesky.git
   ```
3. Open the project folder in Unity Hub. The editor will regenerate the `Library` folder on first open.

## Project Structure

- `Assets/Scripts/` — Game scripts
- `Assets/Scenes/` — Game scenes
- `Assets/Mirror/` — Mirror networking library
- `Assets/models/` — 3D models
- `Assets/skybox/` — Skybox textures
